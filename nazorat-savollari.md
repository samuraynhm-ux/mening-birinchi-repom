# Nazorat savollariga javoblar



## 1. Repozitoriy nima?

Repozitoriy — loyiha fayllari va ularning o‘zgarishlar tarixi saqlanadigan joy. Uni jamoa ishlatadigan loyiha papkasiga o‘xshatish mumkin.



## 2. README fayli nima uchun kerak?

README.md loyiha haqida qisqacha ma’lumot, maqsad va foydalanish yo‘riqnomasini ko‘rsatadi; repoga kirgan odam avval shu sahifani ko‘radi.



## 3. Commit changes tugmasi nima qiladi?

Bu tugma o‘zgarishlarni repoga saqlaydi va tarixga yangi qayd sifatida qo‘shadi.



## 4. Issue nima va unga qanday ma’lumotlar yoziladi?

Issue — bajariladigan vazifa, xato yoki taklif uchun kartochka. Unda sarlavha, tavsif, bajarilish shartlari, mas’ul, yorliq va izohlar bo‘lishi mumkin.



## 5. Izohda @ belgisi nima uchun ishlatiladi?

@username muayyan foydalanuvchini tilga olib, unga bildirishnoma yuborish uchun ishlatiladi.



## 6. Kartochka qachon yopiladi?

Vazifaning tavsifida ko‘rsatilgan bajarilish shartlari bajarilib, natija tekshirilgach issue yopiladi.
